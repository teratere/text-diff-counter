# 📝 テキスト差分チェッカー & 文字数カウンター (Text Diff & Counter)

> **🌐 Live Demo:**  
> ブラウザで今すぐ使える公開版はこちら 👉 **[https://selfup.net/diff/](https://selfup.net/diff/)**

Geminiなどの生成AIによる推敲・リライト前後のテキストを貼り付けるだけで、**「変更箇所（追加・削除・置換）のハイライト」**と**「文字数・原稿用紙換算・読了目安時間の増減」**をリアルタイムにワンストップ検証できるシングルファイルWebツールです。

外部サーバーへテキストを一切送信しない完全ブラウザ完結型（ローカル処理）のため、未公開の下書きや機密文章も安心してチェックできます。

---

## 🌟 主な機能 (Features)

### 1. スマートテキストDiff（差分比較）
- **文字・単語・行単位の切り替え:** 日本語の微小な言い回し修正（文字単位）から、段落単位の構成変更（行単位）まで対応
- **2つの表示ビュー:**
  - **インライン統合表示 (Unified):** 1つの文章内で削除（赤背景＋取消線）と追加（緑太字）を色分け表示
  - **左右並列表示 (Side-by-Side):** 修正前と修正後を左右に並べ、スクロールを同期させて見比べ可能
- **ワンクリック操作:** 左右入れ替え、クリア、クリップボードコピー、サンプルテキスト挿入

### 2. リアルタイム文字数 & 原稿換算サマリー
- **文字数差分バッジ:** 修正前と修正後の差（例: `+45字` / `-30字`）をカラーで即座に算出
- **400字詰原稿用紙換算:** 一般的な原稿用紙の枚数および行数を自動換算
- **読了目安時間:** 黙読（分速500字基準）およびスピーチ・音読（分速300字基準）を秒単位で計算
- **詳細統計:** 総文字数、空白除外文字数、行数、段落数をリアルタイム表示

### 3. 完全ローカル・プライバシー保証 (Client-side Only)
- すべての差分計算および文字数集計はブラウザ内のJavaScript（jsdiff）のみで完結
- 外部サーバーへの通信は一切行われないため、安全に文章を投入可能
